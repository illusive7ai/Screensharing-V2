# Screensharing-V2
A peer-to-peer screen sharing application using WebRTC and Socket.io for signaling.

## Features

- 🖥️ **Real-time screen sharing** — share your entire screen or specific windows
- 🎥 **Dual video feeds** — see both local (your screen) and remote (viewer) streams
- ⚡ **Low latency** — WebRTC peer-to-peer connection
- 🔌 **Simple one-click start** — just click "Share Screen"
